# Punla Flashcard JSON Import

## Release

Punla 2.3 (`versionCode 14`)

## Purpose

Punla can import flashcard decks generated by ChatGPT or other tools as JSON files. This gives the user a direct workflow:

1. Ask ChatGPT to create a Punla flashcard deck from notes, a lecture, or a source document.
2. Download the generated `.json` file.
3. Open **Punla → Flashcards → Import JSON deck**.
4. Review the import preview.
5. Tap **Import**.

Inside an existing deck, **Import JSON** adds the cards to that deck instead of creating a new one.

## Canonical format

```json
{
  "format": "punla-flashcards",
  "version": 1,
  "deck": {
    "name": "AGRI 31 — Photosynthesis",
    "courseCode": "AGRI 31",
    "description": "Review cards from the photosynthesis lecture"
  },
  "cards": [
    {
      "front": "What organelle performs photosynthesis?",
      "back": "The chloroplast.",
      "hint": "Contains chlorophyll"
    },
    {
      "front": "Where do the light-dependent reactions occur?",
      "back": "In the thylakoid membranes."
    }
  ]
}
```

`hint`, `courseCode`, and `description` are optional.

## Compatible aliases

The importer is intentionally tolerant so generated files do not have to match one exact vocabulary.

Front-side aliases:

- `front`
- `question`
- `prompt`
- `term`

Back-side aliases:

- `back`
- `answer`
- `response`
- `definition`

Hint aliases:

- `hint`
- `clue`

The root card array may be called either `cards` or `flashcards`.

## Bare-array format

Punla also accepts a plain card array:

```json
[
  {"question": "What is salinity?", "answer": "The concentration of dissolved salts in water."},
  {"question": "What is pH?", "answer": "A measure of acidity or alkalinity."}
]
```

When imported from the deck library, a bare array becomes an **Imported deck**. When imported from inside a deck, its cards are added to that deck.

## Validation and safety

- Files are limited to approximately 4 MB.
- At most 5,000 cards are imported at once.
- Cards without both a usable front and back are skipped.
- A preview is shown before data is written.
- Unknown/newer format fields are ignored with a warning where appropriate.
- Imported IDs are generated by Punla, so external JSON cannot overwrite existing cards by supplying IDs.
- Imported cards always start as fresh reviews. External `mastery`, `reviewCount`, `correctCount`, `dueAt`, or similar fields are ignored.
- New-deck imports are inserted transactionally so the deck and its cards are saved together.

## Recommended ChatGPT request

A convenient request is:

> Create a Punla flashcard JSON file from these notes. Use format `punla-flashcards` version 1, include deck name/course code/description, and put each card in `cards` with `front`, `back`, and optional `hint`.
